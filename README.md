# 🏡 Gurgaon Real Estate Market Analysis (EDA)

## 📌 Project Overview

This project analyses the residential real estate market in **Gurgaon** using **Exploratory Data Analysis (EDA)** with Python.

As a **Data Analyst** at a real estate advisory firm, the objective is to extract meaningful insights from residential property data collected across multiple localities in Gurgaon. These insights can help **buyers, investors, developers, and real estate consultants** make informed, data-driven decisions.

The dataset contains information such as:

* Property price
* Area (sq. ft.)
* BHK configuration
* Property type
* Builder/Developer
* Property status (Ready-to-Move / Under Construction)
* RERA approval status
* Locality

---

## 🎯 Business Questions

This analysis answers the following business questions:

* Which is the costliest property in the dataset?
* Which locality has the highest average property price?
* Which locality has the highest price per square foot?
* Do ready-to-move properties cost more than under-construction properties?
* Do RERA-approved properties command a price premium?
* How does property area affect price?
* Which BHK configuration has the highest average price?
* Which property type (Apartment, Floor, Plot) is the most expensive?
* Which builders consistently list higher-priced properties?
* Are larger homes always more expensive per square foot?

---

## 📊 Project Workflow

The analysis is organised into the following steps:

1. Data Loading

   * Import the dataset and inspect its structure.

2. Data Understanding

   * Explore data types, missing values, duplicates, and basic statistics.

3. Data Cleaning

   * Handle missing values, remove inconsistencies, and prepare the data for analysis.

4. Exploratory Data Analysis (EDA)

   * Answer each business question using descriptive statistics and visualisations.

5. Key Insights

   * Summarise the findings and highlight important trends discovered during the analysis.
